# GUNDAM OS — Android ランチャー

ニアガラランチャー風のミニマルUIに、ガンダム（U.C.）のコックピットHUDっぽい世界観をのせた、
個人用のAndroidホームアプリです。インストール済みアプリは**元のアイコン**でそのまま表示します。

## 特徴
- 縦一列のミニマル表示（ニアガラ風）
- 右端の A〜Z 早送りバーで素早くジャンプ
- ホームに「お気に入り」を表示（アプリ長押しで追加/削除）
- 検索、アプリ情報、アンインストール
- 暗いコックピットHUD調のデザイン（トリコロールの差し色・等幅フォント・計器風の時計/バッテリー表示）

## スマホへの入れ方（Android Studio 不要）
1. GitHub の **Actions** が自動でビルドし、**Releases** の `latest` に `gundam-os.apk` が作られます。
2. スマホのブラウザで、このリポジトリの **Releases → latest → gundam-os.apk** を開いてダウンロード。
3. 「提供元不明のアプリ / このソースを許可」を有効にしてインストール。
4. ホームボタンを押すと「どのランチャーを使う？」と聞かれるので **GUNDAM OS** を選択。

## 操作
- アプリを**タップ**：起動
- アプリを**長押し**：お気に入り追加/削除・アプリ情報・アンインストール
- ホームで**上スワイプ** または **[ALL UNITS]** ：全アプリ一覧
- 全アプリ画面の右端バー：A〜Z へジャンプ／上部で検索

## 技術メモ
- Kotlin + Jetpack Compose、minSdk 26 / targetSdk 34
- 追加のバイナリ素材なし（アイコンはベクター、フォントは等幅を使用）
- CI: GitHub Actions（`.github/workflows/build.yml`）で debug APK をビルドして Release に添付
